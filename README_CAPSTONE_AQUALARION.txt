
How to run:
1) Create a MySQL database and import aqualarion_app.sql.
2) Update DB env vars in connection.php if needed:
   DB_HOST, DB_NAME, DB_USER, DB_PASS
3) Put all files in your PHP web root.
4) Open login.php in a browser.
